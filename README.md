# 抖音截流工作台（便携版）

本地运行的抖音线索采集与评论分发工具。基于 **Chrome 远程调试（CDP）** 驱动你自己的浏览器，
所有数据只保存在本机 JSON 文件里，不上传任何服务器。

## 一、依赖要求

| 依赖 | 要求 | 说明 |
|---|---|---|
| Windows | 10 / 11 | 需要 PowerShell |
| Node.js | **20 或更高** | https://nodejs.org/ 安装后重开命令行 |
| Google Chrome | 任意较新版本 | 首次启动会打开独立配置目录，需自行扫码登录抖音 |
| Python（可选） | 3.10+ | 仅在 pipeline 的评论清洗（scrapling_bridge）用到；缺省时自动跳过并继续 |

本工具**没有 npm 第三方依赖**，无需 npm install。

## 二、快速开始

1. 把整个文件夹解压到任意目录（**不要放在只读目录**）
2. 双击 **启动.cmd**（或右键 start.ps1 → 使用 PowerShell 运行）
3. 首次启动会打开专用 Chrome，请在其中**登录你的抖音账号**
4. 浏览器会自动打开工作台：http://127.0.0.1:8090/
5. 停止时双击 **停止.cmd**

> 专用 Chrome 使用包内目录 `dy-main` 保存登录态；下次启动无需重新登录。
> 关闭该 Chrome 窗口不影响工作台；反之工作台重启也不影响登录态。

## 三、功能面板

| 面板 | 用途 |
|---|---|
| 🎬 完整流程 | 输入视频关键词 → 多标签并行搜索视频 → 并行爬取评论 → 按评论关键词筛选 → 合并进评论池（支持暂停） |
| 🔎 实时搜索 | 在已有视频集合上增量扫描新评论 |
| 📋 评论筛选 | 按主题/内容/日期/地域筛选评论；勾选后用统一文案分发回复 |
| 🔴 实时监控 | 监听已打开直播间的可见弹幕，命中关键词后沉淀线索 |
| ✅ 确认队列 | 查看已入队的回复任务与执行结果 |
| 💬 私信准备 | 逐条打开用户主页 → 点私信 → 预填文案，**停在发送前等人工确认** |
| 🔐 登录状态 | 检查/刷新抖音登录二维码 |

### 关键词匹配说明（重要）

- **视频关键词**采用「分词 + 顺序无关」匹配。例如搜 `怎么充值codex` 会拆成 `[充值 + codex]`，
  标题里同时出现这两词即命中——因为抖音标题几乎不会出现完整连续串，整串匹配会把结果全过滤成 0。
  工作台会显式提示本次是否为分词匹配、命中多少。
- **评论关键词**为「任意字命中」：评论里出现关键词中的任意一个有效字符即入选（召回高、噪音也高，
  建议用更有区分度的词）。

## 四、安全边界（请务必遵守）

- 只处理**本人或明确授权**的账号与直播间/视频页面。
- 保留人工确认环节：默认**不自动发送**任何回复或私信；私信准备完成后停在页面等你点发送。
- 不读取、不导出 Cookie / Token / 密码；敏感信息不写入代码或配置。
- 建议使用专门的小号做截流，并与主号隔离；首条文案不要带联系方式。
- 遇到验证码、账号异常、平台限制时工具会停下并提示，**不做绕过**。

## 五、已知限制（如实说明）

1. **图文帖（note）的评论回复暂不支持**：抖音网页版把图文帖评论区做成右侧小浮层，
   深评论会被虚拟列表回收，无法稳定定位「回复」按钮。这类目标会被标记为
   `skipped（note_post_panel_unsupported）`，不会刷失败记录。建议分发时优先选**普通视频**的评论。
2. **私信需要 sec_uid**：直播线索若拿不到真实 `sec_uid`（DOM 弹幕常被脱敏为 `*****`），
   私信准备会提示 `not_locatable`。需要先接入弹幕数据帧解析（当前包里为 `live_dom_collector.js`，
   只读可见弹幕）。
3. **发送成功率受平台风控影响**：publish 返回空响应即视为被风控拒绝，工具会如实标记失败，不会谎报成功。
4. **多账号**：当前为单账号模式（一个 Chrome 配置）。多号需复制多个包目录、各用独立配置目录与账号。

## 六、数据与隐私

- 所有运行数据都是包目录内的 JSON 文件；分享/分发本包时请**先清空这些文件**或使用随包附带的空白模板。
- 不要把 `dy-main\`（浏览器登录态）、`cookies*.txt`、二维码图片、历史评论/回复记录一起发给别人。

## 七、目录结构

```text
start.ps1 / 启动.cmd          启动（服务 + worker + 浏览器）
stop.ps1  / 停止.cmd          停止后台进程
reply_server/                 本地工作台（server.js + select.html）
pipeline.js                   完整流程：搜索视频 → 并行爬评论 → 筛选合并
scan_comments.js              实时搜索：增量扫描评论
reply_worker.js               评论回复分发 worker（串行、逐条、人工确认）
comment_worker.js             视频评论分发（打开视频 → 填新评论，实验性）
live_dom_collector.js         直播间可见弹幕采集
live_dm_worker.js             私信准备（开主页 → 私信 → 预填，等人工发送）
browser_session.js            浏览器会话/二维码辅助
scrapling_bridge/             评论清洗（可选，需 Python）
*.json                        运行数据（随包为空模板）
```

## 八、常见问题

- **打不开工作台**：先在包目录运行 `启动.cmd`；确认 8090 端口未被占用。
- **分发不出去 / 报 Page.navigate 超时**：通常是浏览器被重启导致 worker 的连接失效——
  当前版本已内置标签页存活检查，会自动重取；若仍异常，用 `停止.cmd` 后重新 `启动.cmd`。
- **提示评论面板未展开**：正常视频会自动展开；图文帖会直接标记跳过（见限制 1）。
- **登录态失效**：在专用 Chrome 窗口重新扫码登录即可，无需改任何配置。
