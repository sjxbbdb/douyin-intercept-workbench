# 配置字段说明（描述性）

> 本文只说明字段语义，**不提供可执行的自动发送命令**；
> 发送类能力默认关闭，需由平台侧开关放行（本记录不含放行逻辑）。

## 抓取与筛选字段

| 字段 | 语义 |
|---|---|
| videoKeyword | 视频搜索关键词（整串不中时退化为分词 + 顺序无关匹配） |
| commentKeywords | 评论关键词，空格分隔 |
| commentMatchMode | 匹配模式：单字命中 / 二字词 / 字面包含（建议字面包含，噪音最低） |
| maxVideos | 单轮最多处理的视频数 |
| dateStart / dateEnd | 评论时间窗（createTime 落在此区间内才纳入） |
| skipNotes | 是否排除图文帖（其评论区为浮层，定位不稳定） |

## 发送类字段（默认关闭）

| 字段 | 语义 | 默认 |
|---|---|---|
| autoReply | 是否把命中评论加入回复队列 | false（需显式放行） |
| autoDm | 是否把命中评论者加入私信队列 | false（需显式放行） |
| 单批上限 | 一次运行最多处理条数 | 建议 ≤5 |
| 最小间隔 | 两条发送之间的间隔 | 建议 ≥45 秒 |
| 每日配额 | 当日发送上限 | 建议 ≤20 |
| 空响应处置 | 平台返回空响应 | 当日熔断，不再发送 |

## 状态语义

| 状态 | 含义 |
|---|---|
| confirmed | 取得平台响应且平台确认成功 |
| unknown | 未取得平台响应；**不得自动重试，不得进入下游环节** |
| failed | 明确失败（含账号级限制、页面不可见等） |
| skipped | 依规则跳过（如私密账号、评论区不渲染） |
