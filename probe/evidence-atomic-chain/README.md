# evidence-atomic-chain —— 原子链路实验观察材料

本目录存放「视频搜索 → 评论采集 → 严格筛选 → 评论回复 → 私信触达」链路的**脱敏实验观察**与**方法沉淀**。

> ⚠️ 本目录是**观察记录，不是交付证明**。
> 输入框清空、对话回显、公屏回显均不构成送达证明；除平台响应外的结果一律视为 unknown。

## 文件

| 文件 | 说明 |
|---|---|
| WORKLOG.md | 工作日志：环境、问题→原因→观察结果对照 |
| board-*.html | 证据图生成源（静态 HTML，不含脚本与外链） |
| 01..05-*.png | 脱敏证据图（2 倍分辨率） |
| REFERENCE-CONFIG.md | 配置字段说明（**描述性，不含可执行发送命令**） |

## 与 sidecar 的关系

本目录**未接入** `probe/*.py`，也不代表 sidecar 已具备这些能力。
接入所需步骤与未验证边界见 `probe/EVIDENCE-ATOMIC-CHAIN.md`。

## 载体说明

- 证据图为**静态展板截图**：由本地 HTML 渲染后离屏截取，内容全部为脱敏文本；
- 展板不联网、不执行任何脚本、不包含真实昵称或账号数据；
- 可执行参考脚本**不在本目录**（如需保留将另开独立 PR，改为只读 fixture、默认禁止发送、不含原始 PII、不连接真实 CDP）。

## 脱敏声明

所有图形与文本均不含昵称、sec_uid、cid、Cookie、token、会话原文；
示例中的用户一律写作「用户A/B/C」等占位符。
