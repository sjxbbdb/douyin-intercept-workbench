6. 本轮真机解决的问题

· 广场式房间地址：房间号在 ?live_web_rid= 里 → 按房间号归一（原报 target.roomId path is required / URLPolicyError）
· 隐藏浮层假阳性：Semi 浮层隐藏时位于 (-9947,-9941) 却仍有尺寸 → 菜单判定必须"在视口内且命中自己"
· 平台确认框「单次只支持艾特一个人」是全屏遮罩 → 回复前清空输入框残留 + 插入提及后"边等边看"
· 虚拟列表：页面内存 200 条、DOM 只渲染十几行 → 候选只取"此刻渲染在列表内"的可见行
· 长弹幕被平台截断 → 定位改为"完全相同或前缀匹配（≥6 字）"
· 观众身份不一定可见（占位 uid=111111）→ 错误页如实报 profile_not_found；身份不可见不私信
· 私密账号 / 不接受陌生人私信 → 跳过（blocked + skipped），换下一个目标，不记成失败
· 输入必须真实按键（逐字 char 事件，0.1~0.9 秒/字），不能用 insertText
