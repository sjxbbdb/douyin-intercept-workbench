### 3.1 关于「送达」的严格口径

- **输入框清空**：只说明客户端接受了输入，**不等于对方收到**；
- **对话区回显**：是本地客户端渲染结果，**不等于平台投递成功**；
- **公屏回显**：同理，不能当作送达证明；
- 只有拿到**平台响应**（评论发布接口、私信发送接口返回的成功状态码）才可作为该次动作的平台侧依据；
- 其余一律记 **unknown**，并且 **unknown 不得自动重试，也不得进入下游环节（不进入私信）**。

## 4. 方法沉淀（供 sidecar 接入参考）

### 4.1 定位三原则

1. **只认可见节点**：页面可能同时存在隐藏与可见的同名容器，querySelector 可能命中隐藏那份（宽度 0）→ 取宽度最大者；
2. **原子操作**：定位 → 滚入视口 → 点击 → 检测结果在同一次求值内完成，避免虚拟列表在两次调用间回收节点；
3. **兜底用 DOM click**：几何定位失败时直接触发元素点击，不要求元素位于视口内。

### 4.2 文本匹配的三类差异

| 差异 | 现象 | 建议修法 |
|---|---|---|
| 零宽字符 | 昵称/正文混入 U+200B–U+200F、U+034F，比对永不等 | 两侧剔除；昵称只作优先项 |
| 表情标记 | 归一化把表情标记整段删除，而页面侧只删方括号 | 两侧采用同一归一化规则 |
| 同文多条 | 复制粘贴导致误点他人评论 | **以评论 ID 为首要依据**；正文匹配仅在无稳定 ID 时使用；纯数字正文只作最后兜底 |

### 4.3 评论关键词匹配模式（观察结论）

| 模式 | 行为 | 风险 |
|---|---|---|
| 单字命中 | 关键词拆为单字，命中任意一字即入选 | **噪音极大**（求带/手里有资金/111 → 求/带/手/里/有/资/金/1） |
| 二字词 | 整串或二字词命中；纯数字不切分 | 中等 |
| 字面包含 | 必须包含完整关键词 | 召回低但准确 |

## 5. 失败与未决状态（如实记录）

| 状态 | 含义 | 处置 |
|---|---|---|
| 评论不存在于可见列表 | 接口返回有、页面不渲染（已删/折叠） | 记 skipped，不重试 |
| 发布无平台响应 | 编辑器交互完成但未取得平台响应 | 记 **unknown**，不重试、不进入私信 |
| 输入框未出现 | 面板未展开（标签页不可见等） | 记失败并保留原因 |
| 私密账号 | 主页可见账号级限制文案 | 跳过，等待人工 |
| 验证码 / 滑块 | 出现即停止 | **不识别、不绕过**，等待人工 |
