# 本文件夹说明

本文件夹是**仓库结构的原样快照**（不含 .git 与 legacy/），目的是让 P0 骨架
**可以直接运行**：

```bash
node test/run.js                 # L1/L2/L3 应全绿
node scripts/verify-handover.js  # 交付终检
```

## 为什么文档在这里重复了一份？

因为测试与终检脚本要读取**同仓相对路径**的文件：

- `test/contract/consistency.test.js` 会读 `shared/protocol.md`，
  校验代码里的常量（verdict 闭集、错误码、失败归因码）与契约逐项一致
- `scripts/verify-handover.js` 会扫 `docs/`、`shared/`、`plans/`，
  校验文档到位情况与关键数值一致性

所以这里必须保持原始目录结构，文件不能改名或移动。
