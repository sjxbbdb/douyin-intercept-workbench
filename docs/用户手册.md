# 第一章 这个工具是干什么的

## 1.1 一句话说清

**它帮你在抖音上自动回复别人的留言和私信。**

比如有人在你视频下面评论"这个东西多少钱"，它可以自动回一句"私信你啦"。

## 1.2 具体能做什么

| 能做的事 | 说明 |
|---|---|
| ✅ 自动回复视频评论 | 有人在你的视频下评论，自动回他 |
| ✅ 自动回复直播弹幕 | 有人在直播间提到你设的关键词，自动回他 |
| ✅ 自动发私信 | 给评论过/互动过的人发私信 |
| ✅ 收集客户线索 | 把对产品感兴趣的人整理成名单 |
| ✅ 手机电脑都能看的数据看板 | 看今天回了多少人、效果怎么样 |

## 1.3 它不能做什么

| 不能做的事 | 说明 |
|---|---|
| ❌ 不能保证账号不被封 | 见第三章，这是重点 |
| ❌ 不能绕过抖音的验证码 | 出现验证码时必须你本人处理 |
| ❌ 不能代替你做内容 | 它只是回复工具，不会帮你做视频 |
| ❌ 不能保证回复有效果 | 有没有转化取决于你的话术和产品 |

## 1.4 它是怎么工作的（了解即可）

它在**你自己的电脑上**开一个浏览器，用**你自己的抖音账号**去操作。

**所有数据都在你自己电脑里**，我们的服务器只知道"你用了多少条额度"，不知道你回复了谁、说了什么。

# 第二章 十分钟装好并用起来

## 2.1 你需要准备什么

| 需要 | 要求 |
|---|---|
| 一台电脑 | Windows 10 或 11 |
| 一个抖音账号 | **建议专门注册一个小号**（见 3.4） |
| 我们给你的账号密码 | 找客服要，自己不能注册 |
| 网络 | 能正常上抖音就行 |

## 2.2 安装步骤（照着做）

**第 1 步**：把压缩包解压到一个**普通文件夹**

> ⚠️ 不要解压到 `C:\Program Files\` 这种系统目录，会导致没有写入权限。
> 建议解压到 `D:\抖音助手\` 这样的地方。

**第 2 步**：双击 `启动.cmd`

**第 3 步**：会弹出一个浏览器窗口，请在里面**用手机扫码登录你的抖音账号**

> ⚠️ 这里说的是**抖音账号**，不是我们给你的那个账号。
> 我们给你的账号密码，是用来登录工作台界面的。

**第 4 步**：浏览器会自动打开工作台页面

**第 5 步**：用**我们发给你的账号密码**登录工作台

**装好了。** 关掉软件时双击 `停止.cmd`。

## 2.3 装好之后你会看到什么

界面左边是一排菜单，从上到下：

| 菜单 | 用途 |
|---|---|
| 实时监控 | 看直播间的互动情况 |
| 线索确认 | 挑选要联系的人 |
| 任务配置 | 设置关键词和回复话术 |
| 分发队列 | 看正在回复和已回复的任务 |
| 账号状态 | 检查抖音账号有没有掉线 |
| 数据看板 | 看今天的成绩 |

## 2.4 第一件要做的事：设置回复话术

在"任务配置"里设置：

- **关键词**：别人说什么的时候你要回复他。比如填 `多少钱,价格,怎么卖`
- **回复话术**：回复什么内容

> 💡 **重要建议**：话术至少准备 **5 条不同的**。
> 因为如果 50 个人收到一模一样的回复，抖音会认为你在发垃圾消息。
> 系统会自动轮换使用这几条，但你需要先把它们填进去。

# 第三章 封号风险，你必须知道的事

> **这一章是全篇最重要的内容，请务必读完。**
> 不读这一章直接用，是很多账号被封的原因。

## 3.1 先说实话：为什么会封号

抖音不希望有人在上面做营销。当它觉得一个账号**像机器人在发广告**时，就会限制或封禁这个账号。

## 3.2 什么样的行为最容易被封

按危险程度排序：

| 危险程度 | 行为 | 为什么危险 |
|---|---|---|
| 🔴 最危险 | **新号第一天就大量发私信** | 这是封号第一原因，新号没有信用记录 |
| 🔴 最危险 | **一天发大量私信给陌生人** | 抖音本来就不鼓励陌生人私信 |
| 🔴 最危险 | **很多人收到一模一样的内容** | 一眼就能看出是群发 |
| 🟠 很危险 | **每隔固定几秒发一条，24 小时不停** | 真人不可能这样，太规律了 |
| 🟠 很危险 | **收到回复立刻秒回** | 真人需要时间看和打字 |
| 🟡 有风险 | 回复内容和你的账号定位完全无关 | 容易被判定为营销号 |

## 3.3 我们的工具会怎么保护你

我们已经内置了这些保护，**而且你无法关闭**（这是故意的，因为保护你就是保护我们自己的生意）：

| 保护措施 | 具体做法 | 你能改吗 |
|---|---|---|
| 新号观察期 | 前 3 天**只收集，不发送** | ❌ 不能 |
| 逐步放量 | 第 4-7 天每天最多 10 条，第 8-14 天 25 条 | ❌ 不能 |
| 私信单独限量 | 私信比评论限制严格得多 | ❌ 不能超过上限 |
| 相似内容拦截 | 两条内容太像，第二条会被拒绝 | ❌ 不能 |
| 自动放慢 | 发送间隔随机变化，不是固定时间 | ✅ 可以调更慢 |
| 夜间休息 | 晚上不发，只在 8:00-23:00 工作 | ✅ 可以调更短 |
| 出问题就停 | 遇到验证码等异常，自动停下等你处理 | ❌ 不能 |

## 3.4 你必须要做的三件事

### 第一件：用专门的小号 ⭐ 最重要

**不要用你的主号。** 主号里有你的客户、粉丝、历史内容，一旦出问题损失很大。

花点时间注册一个专门做这件事的号，用它来跑工具。这个号的定位就是"客服号"。

### 第二件：前三天什么都别发

新号前三天处于**观察期**，工具会自动只收集不发送。

**请不要想办法跳过这一步。** 前三天让账号正常使用（刷刷视频、点点赞），让抖音觉得这是个正常用户。

### 第三件：话术要像人说的话

| ❌ 不要这样写 | ✅ 建议这样写 |
|---|---|
| "加V：abc123 领取资料" | "我整理了一份，需要的话我发你" |
| "点击链接购买" | "你是想了解哪方面呀？" |
| 同一句话发给所有人 | 准备 5 条以上，系统轮换 |

## 3.5 关于"额度"和"半年套餐"，一个容易搞错的地方

> ### ⚠️ 买了半年套餐，不等于半年内可以无限发
>
> 你的套餐是**预付的回复条数**（比如 4500 条）。
>
> 但**每天能发多少条是由安全上限决定的**，不是由套餐决定的。
>
> 举例：你的账号处于稳定期，每天最多发 30 条。那么半年最多发 30 × 180 = 5400 条左右。
>
> **套餐到期时没用完的条数，按套餐规则处理。**

我们把你买的叫做"额度"，把它理解成**预付的饭票**，而不是"随便吃"。

## 3.6 万一账号被封了怎么办

**第一，不要慌。** 很多情况只是临时限制，不是永久封号。

**第二，先去抖音 App 里看封禁原因和期限。** 通常会有提示。

**第三，如果是我们自己操作失误导致的**（比如软件 bug 导致重复发送），请联系我们，我们会核实处理。

**第四，如果是因为平台规则变化或者你配置了高风险设置**，这个损失需要你自己承担。我们在协议里有说明，这里也再明确一次：

> 本工具可以降低风险，但**无法消除**账号被限制、封禁、内容被下架的可能性。
> 因抖音平台判定、平台规则变更导致的账号处罚和业务损失，我们不承担赔偿责任。

**第五，联系我们时请提供**：账号名、出问题的时间、当时在做什么。我们有完整的操作记录，可以帮你搞清楚发生了什么。

# 第四章 怎么用才安全（照做就行）

## 4.1 每天的发送量上限（系统自动控制）

| 账号阶段 | 时间 | 评论回复 | 私信 | 说明 |
|---|---|---|---|---|
| 观察期 | 第 1-3 天 | 0 | 0 | 只收集，不发送 |
| 预热期 | 第 4-7 天 | 10 条 | 3 条 | 慢慢来 |
| 爬坡期 | 第 8-14 天 | 25 条 | 8 条 | 继续放量 |
| 稳定期 | 第 15 天起 | 30 条 | 10 条 | 正常使用 |

> **为什么私信限制这么严？** 因为抖音对"给陌生人发私信"的管控比评论严格得多。这是平台规则，我们只能适应。

## 4.2 系统自动做的事（你不需要管）

- ✅ 自动控制发送间隔（随机，不规律）
- ✅ 晚上自动休息
- ✅ 内容太像时自动拦截
- ✅ 遇到验证码自动停下
- ✅ 连续失败自动暂停

## 4.3 你需要注意的事（重点）

| 事项 | 怎么做 |
|---|---|
| **看到"需要验证"提示** | 立刻去浏览器里手动处理，处理完点继续 |
| **看到"已暂停"提示** | 看提示原因，通常是达到当日上限或需要验证 |
| **想改话术** | 随时改，改完保存就生效 |
| **想停一下** | 点界面上的**急停按钮**（红色的），立刻停止所有发送 |
| **电脑要关机** | 先点停止，再关机，避免任务中断 |

## 4.4 检查账号健康

界面上有一个"账号健康分"，每天看一眼：

| 显示 | 含义 | 该做什么 |
|---|---|---|
| 绿色 | 一切正常 | 继续用 |
| 黄色 | 接近当日上限 | 正常，明天会重置 |
| 红色 | 被暂停了 | 看原因，按提示处理 |

# 第五章 每天怎么用

## 5.1 开工（每天第一次用）

1. 双击 `启动.cmd`
2. 确认浏览器里的抖音账号**没有掉线**（菜单"账号状态"会显示）
3. 看一眼数据看板，确认昨天的数据正常
4. 检查"急停"是关闭状态
5. 开始工作

## 5.2 收工（每天结束时）

1. 看一眼今天的成绩（看板）
2. 如果还有未完成的回复任务，等它跑完
3. 双击 `停止.cmd`
4. **不需要退出抖音账号**，下次启动会自动记住

## 5.3 一周看一眼

- 回复效果怎么样（有多少人真的回复了你）
- 哪些关键词效果好、哪些没用
- 话术需不需要换

# 第六章 出问题了怎么办

## 6.1 常见问题速查

| 症状 | 原因 | 怎么办 |
|---|---|---|
| 打不开工作台页面 | 服务没启动 | 先双击 `启动.cmd` |
| 提示"登录已过期" | 工作台登录失效 | 重新输入我们给你的账号密码 |
| 提示"抖音账号未登录" | 抖音掉线了 | 在浏览器里重新扫码登录 |
| 回复不出去 | 抖音账号掉线或达到上限 | 看提示，检查账号状态 |
| 一直显示"运行中"但没动静 | 可能是上次异常退出 | 点停止，重新启动 |
| 提示"积分/额度不足" | 额度用完了 | 联系客服充值 |
| 提示"需要验证码" | 抖音要求验证 | **必须你本人去浏览器处理**，我们不做绕过 |
| 电脑很卡 | 开的网页太多 | 关掉不需要的网页，减少并行数量 |

## 6.2 什么时候该找客服

- 额度不对（比如觉得扣多了）
- 一直发不出去，自己解决不了
- 账号出现异常提示
- 想调整套餐

**找客服时请提供**：账号名 + 问题出现的时间 + 界面截图。这样我们能快速查记录。

## 6.3 什么情况我们会拒绝处理

- 你要求我们帮你**绕过验证码**——这个我们不做，也做不了
- 你要求我们把限制**调到你账号等级以上的上限**——我们不能，这是为了保护你
- 你要求我们**保证不封号**——我们做不到，也不会承诺

# 第七章 常见问题

**Q：会不会封号？**
A：有这个可能。我们已经内置了很多保护措施降低概率，但没有任何工具能保证不封号。请用专门的小号。

**Q：为什么前三天不能发？**
A：新号没有信用记录，第一天就大量发送是最容易被封的行为。前三天让账号正常使用，是给账号"养信用"。

**Q：为什么私信限制这么严？**
A：抖音对陌生人私信的管控本来就很严格。这不是我们故意限制你，是平台规则决定的。

**Q：我的数据安全吗？**
A：你的回复内容、客户信息都存在**你自己电脑里**，我们的服务器只知道你用了多少条额度。我们看不到你回复了谁、说了什么。

**Q：可以在多台电脑上用吗？**
A：同一时间只能一台。换电脑用需要先在前一台退出。

**Q：能同时管多个抖音号吗？**
A：可以，在界面上添加多个账号，每个账号独立运行、独立计数。

**Q：额度用完了怎么办？**
A：联系客服充值，或者用充值码自己兑换。

**Q：买了半年套餐，用不完会怎样？**
A：套餐有有效期。到期后未使用的部分按套餐规则处理，具体请咨询客服。

**Q：回复的内容能带联系方式吗？**
A：**强烈建议不要。** 带微信号、手机号、链接的回复很容易被判定为营销，风险明显更高。建议先建立对话，再在私信里沟通。

**Q：能改发送速度吗？**
A：可以调**更慢**，不能调更快。更快意味着更高风险，我们不允许。

**Q：我不懂技术，能学会吗？**
A：能。日常操作就是"双击启动 → 看界面 → 双击停止"三步。其他都是自动的。

| 用工具冒充他人或官方账号 | 违法 |
| 把账号借给他人使用 | 出了问题无法追溯 |

# 第九章 名词解释

| 名词 | 通俗解释 |
|---|---|
| **额度 / 积分** | 你预付的"回复条数"。回复成功一条扣一次，失败不扣 |
| **关键词** | 别人说的话里出现这个词，就触发你的回复 |
| **话术** | 你要回复的内容，建议准备多条 |
| **观察期 / 预热期** | 新账号的阶段，发送量逐步放开 |
| **急停** | 一个红色按钮，点了立刻停止所有发送 |
| **熔断** | 系统发现异常时自动暂停，保护账号 |
| **线索** | 对产品感兴趣的潜在客户 |
| **验证码** | 抖音用来确认"你是真人"的验证，必须你本人处理 |

# 最后的话

这个工具能帮你节省大量重复劳动，但它不是"躺赚机器"。

**它做得好的前提是：你把它当成一个需要精心使用的账号运营工具，而不是一个能无限群发的营销机器。**

我们宁愿你每天只发 10 条但账号活一年，也不愿你一天发 500 条然后号没了——后者对我们也是损失。

有任何问题，联系客服。
