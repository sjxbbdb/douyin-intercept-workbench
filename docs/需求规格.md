## 为什么拆

2026-09-19 项目定位由「抖音自动回复工具」更迭为
**「可承载多种专业分化工作流的 Agent 平台」**（见 `docs/项目章程.md`）。

原来的单份需求规格把**平台机制**（登录、计费、审计、看板）与
**抖音行业知识**（三来源、预热曲线、话术、DOM 技巧）写在同一份文档里。
这带来一个具体的后果：**每加一个领域，都要改动平台文档**——
而平台文档一旦被领域内容污染，就再也无法回答"这条规则适不适用于我的领域"。

因此按 `docs/项目章程.md` §七 的三层骨架拆分。
